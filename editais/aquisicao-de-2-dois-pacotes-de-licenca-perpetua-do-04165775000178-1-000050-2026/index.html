Informações do órgão

A contratação é necessária para substituição do Microsoft SQL Server 2005 Standard Edition, em situação de End of Life (EoL) desde 12 de abril de 2016, utilizado como sistema gerenciador de banco de dados (SGBD) pelo Sistema Chamador da Spiderware Informática, solução de uso interno responsável pelo gerenciamento dos processos de cobrança, registro, fiscalização, financeiro, contábil e demais operações do CRCAM, distribuída para 40 (quarenta) estações de trabalho via rede local. A empresa desenvolvedora confirmou que o Sistema Chamador é incompatível com outros SGBDs disponíveis no mercado, o que fundamenta a indicação de marca nos termos do art. 41, inciso I, alínea "b", da Lei nº 14.133/2021. A análise técnica completa, incluindo o levantamento de mercado com estudo de alternativas e análise de Custo Total de Propriedade (TCO), consta do Estudo Técnico Preliminar – SEI nº 1425105. A solução consiste na aquisição de 2 (dois) pacotes de licença perpétua do Microsoft SQL Server 2025 Standard Edition, Per Core, cobrindo 4 (quatro) núcleos totais, a ser instalado em máquina virtual com 4 vCores hospedada em servidor com Microsoft Windows Server 2025, em substituição à instância atual do SQL Server 2005. O ciclo de vida da solução compreende: (i) recebimento e validação das chaves de licença; (ii) acionamento da Spiderware Informática no âmbito do contrato vigente para execução da migração; (iii) backup completo das bases de dados do SQL Server 2005; (iv) instalação e ativação do SQL Server 2025 na máquina virtual; (v) validação funcional do Sistema Chamador no novo ambiente; e (vi) desativação do SQL Server 2005. A licença perpétua constitui ativo intangível permanente do CRCAM, sem necessidade de renovação. Parcelamento: não aplicável. O licenciamento Per Core exige cobertura mínima de 4 (quatro) núcleos por instância de servidor — equivalente a 2 (dois) packs —, sendo o objeto tecnicamente indivisível. A aquisição de 1 (um) pack resultaria em uso não licenciado, em violação dos termos da Microsoft.
